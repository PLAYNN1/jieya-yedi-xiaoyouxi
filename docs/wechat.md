# YEDI · 液滴实验

> 本文保留第一阶段微信原型的历史记录，部分玩法和界面已更新。当前版本以浏览器为主，最新玩法、操作和运行方式请见 [项目说明](../README.md)。导入微信时请选择你实际克隆的工程目录。

原生微信小游戏 JavaScript / Canvas 2D 最小可验证原型。项目实际保存在 **D:\YEDI**。不依赖云服务、第三方引擎、npm 包或外部图片。

## 先看效果

在本目录打开终端：

```powershell
cd D:\YEDI
node tools/serve.js
```

浏览器打开 **http://127.0.0.1:4173**。也可以使用 `npm run preview`，无需先安装依赖。如果 4173 端口被占用，先关闭旧预览服务，或设置 `$env:PORT=4174` 后启动。

浏览器使用与小游戏相同的物理、轮廓、绘制和操作代码，仅音频及输入平台适配不同。请通过本地服务运行，不要直接双击 HTML；浏览器的文件协议会限制音频读取。服务仅绑定本机回环地址。

## 微信开发者工具导入

1. 打开微信开发者工具，在小游戏项目入口选择“导入项目”。
2. 目录选择 **D:\YEDI**，项目名可填 YEDI。开发类型为“小游戏”。
3. AppID 暂时保留 `project.config.json` 中的 `touristappid` 占位；如果当前工具提供“无 AppID / 游客模式”，可以尝试本地模拟。**部分版本或小游戏模式不接受游客占位，此时先用浏览器预览，之后填真实小游戏 AppID 再导入。**不要把占位值当作有效小游戏账号。
4. 使用已有小游戏 AppID 时，在导入界面填写，或把 `project.config.json` 的 `appid` 修改为该 AppID。确认它属于“小游戏”，而不是普通小程序。
5. 无需云开发、不勾选云服务、不需要构建 npm。项目编译类型已经设为 `game`，入口是 `game.js`，配置是 `game.json`。
6. 点击“编译”，模拟器应显示“液滴实验”和顶部膜线。用鼠标模拟触屏操作。
7. 填入真实 AppID、登录有权限的开发者微信后，点击“预览”，使用该微信扫码，在手机验证触屏与音效。若工具提示账号权限或小游戏类目要求，按账号实际情况处理；本地源码不依赖这些服务。

**不需要提供 AppSecret、私钥或其他密钥。**本项目没有自动上传、发布或连接网络服务。

本次自动连接微信开发者工具遇到本机授权超时，**没有完成微信模拟器编译、手机扫码预览或真机帧率验证**。浏览器检查和平台适配契约检查不能替代微信实测。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点按画面下半部，再松开 | 从点按的横向位置发射小滴，自动瞄准中心 |
| 按住下半部后横向拖动，再松开 | 调整目标横坐标，可故意射偏，虚线显示瞄准位置 |
| 顶部“声音 / 静音” | 开关音效，静音会立即停止当前声音 |
| 顶部“重置” | 清空小滴、计数和振动，恢复初始半球滴；保留当前参数和静音选择 |
| 底部“实验参数” | 展开/收起滑块；调脱落阈值、膜线张力、振动阻尼、小滴半径 |
| 浏览器键盘 | 空格发射、R 重置、M 静音、P 参数面板 |

发射间隔 0.22 秒，上限 16 颗在途小滴；支持单指操作，多指不会重复发射。切到后台会暂停，返回不会快进模拟。

## 第一阶段已实现

- 一条两端固定的膜线，65 个节点，中央受载下陷；碰撞和脱落产生局部扰动，沿膜传播并衰减。
- 蓝色初始半球滴附着在膜下；使用单个填充轮廓表现整体液滴，无玻璃材质、晶体高光或球串。
- 小滴撞击带来挤压、横向摆动、面积增加，轮廓以约 0.2 秒的平滑过程增大，并伴随阻尼形变。
- 默认阈值为初始负载的 2.35 倍，默认约 4 次命中触发：1.05 秒内拉长、颈缩，再断裂坠落。颈部没有额外生成串珠小球。
- 断裂后残留少量附着液体作为下一轮种子，膜线卸载回弹；液滴持续重力下落。后续轮次需要的命中数会因残留量不同而变化。
- v0.1.1 本地 PCM WAV：采用用户提供的 `10月8日.MP3` 中约 7.168–7.408 秒、7.902–8.182 秒的两个短音片段，替换第一版振荡器音效。通过降速降调、柔化高频和轻微短延迟，向带吸附感的液体“啵 / 咕”调整；发射较轻，融合更突出，断裂尾音稍长。微信使用 `wx.createInnerAudioContext`，浏览器使用 Web Audio 解码播放；首次交互解锁音频，极早的第一声可能在缓冲完成前跳过。音频不可用时不阻塞画面。原始 MP3 未修改，音色需用户试听确认。
- 120 Hz 固定物理步长，绘制跟随屏幕刷新率；高分屏像素比上限 2，暂停时停止循环；自适应窗口、微信安全区和右上胶囊区域。

这是为验证手感设计的二维近似模型，质量按液体面积记账，并非完整流体求解器。表面形变和断裂经过视觉编排，体积在三维空间不作物理解释。暂不包含混色、复杂悬挂、关卡和发布功能。

## 参数与实现位置

默认值在 `src/simulation.js` 的 `DEFAULTS` 中：

| 参数 | 默认值 | 面板范围 | 影响 |
| --- | --- | --- | --- |
| threshold | 2.35 | 1.6–3.6 | 相对初始负载的脱落阈值 |
| tension | 150 | 70–230 | 膜波传播及邻接耦合 |
| damping | 4.6 | 2–9 | 振动衰减速度 |
| shotRadius | 12 | 9–15 | 小滴大小及每次加入的面积 |
| gravity | 700 | 仅源码 | 发射和坠落的重力加速度 |

阈值降低到当前负载以下会立即开始脱落。已经进入颈缩阶段的脱落不会被修改阈值取消。重置保持面板参数；需要恢复默认参数时刷新预览或重新编译小游戏。

## 源码结构

```text
game.js                   微信平台入口、触屏、安全区、本地音效
game.json                 竖屏配置
project.config.json       小游戏导入配置及 AppID 占位
src/simulation.js         固定步长模拟、融合、断裂、面积守恒
src/renderer.js           Canvas 2D 轮廓、膜线与操作界面
src/app.js                平台共用输入、滑块、缩放及帧循环
src/audio-config.js       微信与浏览器共用的各类音效音量
audio/*.wav               四个已生成音效及两个参考录音裁切源
preview.html / preview.js 浏览器预览入口与平台适配
tools/serve.js            零依赖本地预览服务
tools/make-audio.js       从裁切源重建新版音效；--demo 同时生成试听
tests/simulation.test.js  模拟回归验证
tests/wechat-adapter.test.js 微信入口契约检查（API 桩，非真实微信环境）
outputs/                  截图、验证记录及交付包
```

开发与预览文件已列入小游戏打包忽略规则。无需 `app.js`、WXML、页面配置或浏览器适配器。

## 已做检查与手机验收建议

执行 `npm test` 可复查：命中融合、阈值脱落、自由落体、膜波衰减、射偏、面积守恒、30/120 FPS 结果一致、两组参数极值连续 90 秒发射、重置和节流，以及微信入口在明确 API 桩下的加载、音效池、安全区、单指、取消触摸、窗口变化、前后台切换；全部通过。所有 JavaScript 已做语法检查。API 桩检查不是微信运行环境测试。

浏览器自动操作验证了实际鼠标发射、默认 4 次命中到断裂、静音、重置、参数拖动、射偏、桌面窗口缩放、375×667 移动触屏，以及四个 WAV 的解码播放；记录见 `outputs/browser-verification.json`。截图见 `outputs/01-initial.png` 至 `06-mobile.png`。自动音频检查验证播放 API 与资源可用性，音色与响度仍需亲耳判断。

手机预览建议按顺序检查：初始滴是否贴膜 → 连续点按 4 次并等待融合 → 观察挤压、增长、颈缩 → 看断裂后的膜波 → 开关静音与重置 → 调低阻尼观察更长的回弹 → 切后台再返回 → 连续操作 1 分钟查看右上 FPS。实际微信设备的帧率与声音以真机为准。

新版音效更新后，请刷新浏览器页面或重新编译小游戏，避免正在运行的页面继续使用旧音频缓冲。试听 `outputs/音效试听-v2.wav`，顺序为发射、融合、发射、融合、断裂、落下，音量与游戏一致。可使用 `node tools/make-audio.js --demo` 重建，已包含所需裁切源，无需再次访问桌面原始录音。
